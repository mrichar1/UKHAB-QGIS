# UKHAB-QGIS

Automated generation of a GeoPackage and QGIS project for [UKHAB]([UKHab]https://(ukhab.org) habitat classification.

This project is inspired by the original [UKHAB-QGIS](https://github.com/Skipper-is/UKHAB-QGIS) project - automating the generation of the GeoPackage and Project with a Python script. The original files from this project can be found in the `legacy` directory.

This code has been developed and tested with [QGIS](https://qgis.org/) `4.2` - while it is likely to work with earlier or later versions, this has not been tested - feedback welcome!


## Mapping Habitats

To begin, open the appropriate `ukhab_template.qgz` file for the UKHab version you wish to map with.

There are currently 3 UKHab versions available:

* 2.1 - Draft version (Consultation likely to complete by end 2026).
* 2.01 - Stable version (July 2023)
* 1.0 - Legacy (original) version (May 2018)

The project defaults to `EPSG:27700` (British National Grid).

Each project file contains the following layers:

2 editable mapping groups of layers:
* Proposed - for mapping planned features.
* Baseline - for mapping existing features.

* Boundary line - a layer for drawing a red boundary line around the site.

2 read-only 'data lookup' layers:
* Primary_Codes - primary habitat classification data.
* Secondary_Codes - secondary codes classification data.

The Baseline and Proposed groups subdivide into separate layers for Areas (polygons), Lines (linestrings) and Points (points).

Once a feature is drawn in an appropriate layer, a dialog will appear to record metadata about the feature, with the following input fields, split across 2 tabs:

**Habitat:**

* Habitat L2 to Habitat L5 (L2 mandatory, L3-5 optional) - The habitat type of the feature, at each level. Values are filtered by the previous level.

* Secondary Codes - a multiple selection of all secondary codes, filtered by the selected primary habitat levels.

* Condition (optional) - the condition of the feature: Good, Fairly Good, Moderate, Fairly Poor, Poor

**Metadata:**

* Author - defaults to current QGIS user.

* Created/Updated - defaults to 'now'.

* Area/length (for Area and Line features) - automatically calculated values for the area and/or perimeter/length of the feature.


## Styling

The project has categorized symbology enabled, so that the colour of the feature (Area or Line) is set automatically based on the Level 2 code (e.g. g (Grassland) = green, r (Rivers & Lakes) = light blue etc).


## Versions

There are several versioned directories, corresponding to UKHab classification versions.

The latest formal release is `2.01`, `2.1` is currently in consultation.

The original UKHAB-QGIS project files are to be found in the `1.0` directory. There are some differences in functionality of this project - see the original UKHAB-QGIS project for details.

# Development

## Structure

Each directory contains the following files:

* ukhab_template.gqz - a QGIS Project file to be used as a template for habitat mapping.
* ukhab.gpkg - a GeoPackage used as the basis of the QGIS project file.
* primary_codes.csv - a table of primary codes, habitat names, levels, and geometry types, manually extracted from the PDF schema and XLSX correspondance tables provided by ukhab.org
* secondary_codes.csv - a table of secondary codes, habitat names, associated primary codes, and geometry types, from the same sources.

The Project and GeoPackage are generated by python scripts, the CSV files have been manually curated (hopefully in future this schema data will be provided in a suitable form directly by [UKHab]https://(ukhab.org)).

Primary Codes in the CSV files are sorted to match the UKHab reference guides (PDF)  order of the level 2 categories (g, w, h, f, c, u, s, r, t) and then naturally sorted within each category. This is to allow QGIS users to more easily work alongside the reference guides in the field.

## Configuration

The main configuration settings are found in `config.py`, including paths, layer names, field names/attributes, relationships to non-spatial layers, styling etc.

## Running

**Note**: Make sure to set `SCHEMA_VERSION` in `config.py` to the schema version that you wish to build, and ensure that directory exists and contains the relevant CSV files.

To generate the GeoPackage and QGIS project, run:
`qgis --code create_ukhab.py`

(QGIS will open, generate the project file, and save. QGIS will keep running to allow testing the new project - but DO NOT save any manual changes you make!)
